Before you start — turn on rhythm-test mode. Production pace durations are real days, too slow to bench. Corked collapses them to seconds when it sees either signal:
  1. Add ?rhythmtest=1 to the corked_v6.html URL you're testing in, e.g. corked_v6.html?rhythmtest=1, or
  2. Run localStorage.setItem('corked_rhythm_test','1') once in that tab's console, then reload.
  1. With test mode on, PACE_DURATIONS is { daily: 15s, every-other-day: 30s, weekly: 60s, monthly: 120s }. Every flow below assumes a Weekly pace choice at the rhythm step, so "the gate opens" means 60 seconds after park.
  2. All flows start from the same base chain: a spark, the maturity tree, a grape, then the rhythm picker where you should pick Weekly. From there you'll reach the M2 question — that's where each flow branches.
