Part 0 · Reopen Routing
Tap an element on the label. Same question, same route.
Each element must route to its source mechanism's own question, and re-grading must be rank-up only — a strong second answer should never leave the element worse than it was.
Part A · Substitution Flag + Inline Errand
The founder's own build is not evidence. A real gap deserves an errand.
Substitution answers must never show an errand. Genuine turbid/clearing answers must show one — verbatim, and the parked brief must carry the exact text shown, not a re-fetched one.
Part B · The Swirl
One reopening question. Never twice.
A thin answer may earn one swirl question, same sitting. The regrade after answering it must never rank the element down. Once used, that mechanism never shows a swirl again — including on a later reopen.
Part C · Cork-Gate Resolving Question
Five settled, one left. The last question should sharpen, not repeat.
Exactly one Turbid or Clearing element with the other five Settled must surface a new, sharper /resolve question. Two amber elements must fall back to the plain reopen question instead.
The label is not decoration. Every amber field is a door back into the mechanism that left it that way.
